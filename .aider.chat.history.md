### Общая структура проекта:
- Проект, судя по путям и содержимому, — это эмулятор операционной системы **KolibriOS** (или похожей), написанный на JavaScript/TypeScript.

---

### Основные компоненты:

#### 1. `src/emulator/emulator.js`
- Класс `Emulator` — центральный компонент эмуляции.
- Принимает `surface` (графический буфер), `log` (функция логирования), `options`.
- Поддерживает выбор CPU backend (`cpuBackend`, `cpuHelperBackend`, `cpuWasmHelperBackend`).
- Имеет методы `readMem8/16/32`, т.е. реализует доступ к памяти эмулируемой системы.

#### 2. `src/gfx/surface.js`
- Определяет `createHeadlessSurface(width, height)` — создаёт `HeadlessSurface`, вероятно, для рендеринга в память без DOM.
- Используется в автотестах (см. `tools/autotest-putpaletteimage-rowoffset.js`).

#### 3. `src/ui/session-manager.js`
- `SessionManager` — управляет сессиями/процессами в UI.
- Имеет `desktopEl`, `desktopCanvasEl` — видимо, для отображения рабочего стола.
- Метод `getActiveProcess()` — возвращает активный процесс (если не удалён).

#### 4. `tools/ui-harness.js`
- `HeadlessUiHarness` — класс для headless-тестирования UI.
- Загружает `KosEmu` (KolibriOS runtime), использует `lzma` и `fflate`.
- Имеет `captureSnapshot()` — делает снимок состояния (текущее окно, тексты, кнопки), вероятно, для UI-тестирования.

#### 5. `tools/autotest-putpaletteimage-rowoffset.js`
- Автотест, который:
  - создаёт headless-поверхность 8×4,
  - очищает её,
  - создаёт эмулятор,
  - подменивает `readMem*` — для прямого теста памяти/рисования.
